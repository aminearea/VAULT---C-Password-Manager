  <h1>VAULT - C++ Password Manager</h1>
  <h3>A Modern C++ Command-Line Password Manager</h3>
  <p><b>AES-256-CBC Encryption | Multi-User Support | Polished Terminal UI</b></p>
</div>

<hr>

<h2>Features</h2>
<ul>
  <li><b>Military-Grade Encryption:</b> Uses AES-256-CBC via OpenSSL to secure all vault data.</li>
  <li><b>Multi-User Support:</b> Create multiple independent vault files, each protected by a unique User ID and Master Password.</li>
  <li><b>Interactive Terminal UI:</b> A beautiful, colorized interface with animated banners, box-drawn menus, and progress bars.</li>
  <li><b>Key Derivation:</b> Uses PBKDF2-HMAC-SHA256 with 10,000 iterations to derive encryption keys.</li>
  <li><b>Full CRUD Operations:</b> Add, List, Search, Update, and Delete stored entries.</li>
  <li><b>Password Generator:</b> Generates strong, random passwords of customizable length (8-64 characters).</li>
  <li><b>Session Management:</b> Save & Logout functionality allows switching between accounts without restarting.</li>
</ul>

<hr>

<h2>Prerequisites</h2>
<h3>1. MSYS2 / MinGW</h3>
Install <a href="https://www.msys2.org/">MSYS2</a>, then update packages:
<pre><code>pacman -Syu</code></pre>

<h3>2. OpenSSL Library</h3>
Install the development package inside MSYS2:
<pre><code>pacman -S mingw-w64-ucrt-x86_64-openssl</code></pre>

<h3>3. VS Code</h3>
Install the C/C++ Extension and ensure your terminal uses the MSYS2 UCRT64 shell.

<hr>

<h2>Building and Running</h2>

<h3>1. Project Structure</h3>
<pre><code>project/
|-- include/
|   |-- Crypto.h
|   |-- Entry.h
|   `-- vault.h
|
|-- src/
|   |-- Crypto.cpp
|   |-- vault.cpp
|   `-- main.cpp
|
|-- .vscode/
|   `-- tasks.json
`-- README.md
</code></pre>

<h3>2. Update tasks.json</h3>
<pre><code>{
    "tasks": [
        {
            "type": "cppbuild",
            "label": "C/C++: g++.exe build active file",
            "command": "C:\\msys64\\ucrt64\\bin\\g++.exe",
            "args": [
                "-fdiagnostics-color=always",
                "-g",
                "${workspaceFolder}/src/*.cpp",
                "-I",
                "${workspaceFolder}/include",
                "-o",
                "${workspaceFolder}/src/main.exe",
                "-lcrypto",
                "-lssl",
                "-lws2_32"
            ],
            "options": {
                "cwd": "${workspaceFolder}"
            },
            "problemMatcher": [
                "$gcc"
            ],
            "group": "build",
            "detail": "Task generated by Debugger."
        }
    ],
    "version": "2.0.0"
}
</code></pre>

<h3>3. Compile and Run</h3>
<ol>
  <li>Open the project in VS Code.</li>
  <li>Press <code>Ctrl + Shift + B</code> to build.</li>
  <li>Press <code>F5</code> to run and debug.</li>
</ol>
<p><i>Note: If you get a "Permission denied" error, ensure <code>main.exe</code> is not currently running.</i></p>

<h2>Usage Guide</h2>
<ol>
  <li><b>Welcome Screen:</b>
    <ul>
      <li><code>[1]</code> Authenticate (ID + Password)</li>
      <li><code>[2]</code> Create New Vault Account</li>
      <li><code>[0]</code> Exit</li>
    </ul>
  </li>
  <li><b>Authentication:</b> Enter your User ID and Master Password (3 attempts).</li>
  <li><b>Main Menu:</b>
    <ul>
      <li><code>[1]</code> List Entries | <code>[2]</code> Add Entry | <code>[3]</code> Search Entries | <code>[4]</code> Update Entry</li>
      <li><code>[5]</code> Delete Entry | <code>[6]</code> Generate Password | <code>[7]</code> Change Master Password</li>
      <li><code>[8]</code> Save | <code>[9]</code> Save & Logout | <code>[0]</code> Back to Login</li>
    </ul>
  </li>
</ol>

<h2>Security Architecture</h2>
<ul>
  <li><b>Encryption:</b> AES-256-CBC.</li>
  <li><b>Key Derivation:</b> PBKDF2-HMAC-SHA256 (10,000 iterations).</li>
  <li><b>Salt/IV:</b> Random 16-byte values generated per file.</li>
  <li><b>Key Formula:</b> <code>Key = DeriveKey(UserID + "::" + MasterPassword, Salt)</code>.</li>
</ul>
