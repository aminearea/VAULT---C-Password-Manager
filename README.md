# 🔐 VAULT - C++ Password Manager

A modern, secure, and user-friendly command-line password manager built in **C++** with **AES-256-CBC** encryption. VAULT features a polished terminal UI with full color support, ASCII art, typewriter animations, and multi-user support.

---

## ✨ Features

*   🔒 **Military-Grade Encryption:** Uses AES-256-CBC via OpenSSL to secure all vault data.
*   👥 **Multi-User Support:** Create multiple independent vault files, each protected by a unique `User ID` and `Master Password`.
*   🖥️ **Interactive Terminal UI:** A beautiful, colorized interface with animated banners, box-drawn menus, and progress bars.
*   🔑 **Key Derivation:** Uses PBKDF2-HMAC-SHA256 with 10,000 iterations to derive encryption keys from your credentials.
*   📝 **Full CRUD Operations:** Add, List, Search, Update, and Delete stored entries (Services, Usernames, Passwords, Notes).
*   🎲 **Password Generator:** Generates strong, random passwords of customizable length (8-64 characters).
*   🚪 **Session Management:** Save & Logout functionality allows users to switch between accounts without restarting the program.
*   🛡️ **Robust Input Handling:** Sanitized inputs and buffered output to prevent Windows-specific `\r` (Carriage Return) input bugs.

## 🛠️ Prerequisites

### 1. MSYS2 / MinGW
This project uses the **MSYS2** environment with the **UCRT64** toolchain. 
*   Download and install [MSYS2](https://www.msys2.org/).
*   Update packages:
    ```bash
    pacman -Syu

2. OpenSSL Library

The program requires OpenSSL for encryption. Install the development package inside MSYS2:
bash

pacman -S mingw-w64-ucrt-x86_64-openssl

3. Visual Studio Code (VS Code)

    Install the C/C++ Extension by Microsoft.

    Ensure your VS Code terminal is using the MSYS2 UCRT64 shell.

2. Update tasks.json

Make sure your .vscode/tasks.json contains the correct compiler arguments to link OpenSSL:
json

{
    "tasks": [
        {
            "type": "cppbuild",
            "label": "C/C++: g++.exe build active file",

3. Compile and Run

    Open the project in VS Code.

    Press Ctrl + Shift + B to build the executable.

    Press F5 to run and debug, or execute the generated main.exe from your terminal.

        Note: If you get a "Permission denied" error while building, make sure main.exe is not currently running (kill it in Task Manager or delete the file).

📖 Usage Guide

    Welcome Screen: Choose from:

        [1] Authenticate (ID + Password) - Log into an existing vault.

        [2] Create New Vault Account - Register a new User ID.

    Authentication: Enter your User ID and Master Password. (You have 3 attempts).

    Main Menu: Navigate the options:

        [1] List Entries (Option to reveal passwords)

        [2] Add Entry

        [3] Search Entries (Option to reveal passwords)

        [4] Update Entry

        [5] Delete Entry

        [6] Generate Password

        [7] Change Master Password

        [8] Save

        [9] Save & Logout (Returns to Welcome Screen)

        [0] Back to Login (No Save)

🔐 Security Architecture

    Encryption Algorithm: AES-256-CBC.

    Key Derivation: PBKDF2-HMAC-SHA256 (10,000 iterations).

    Salt: Random 16-byte salt generated per vault file.

    IV: Random 16-byte Initialization Vector generated per save.

    Key Formula: Key = DeriveKey(UserID + "::" + MasterPassword, Salt).

        Because the User ID is part of the encryption key, the password alone cannot decrypt the file without the exact ID.
